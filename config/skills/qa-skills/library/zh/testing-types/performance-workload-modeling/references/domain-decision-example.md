# 领域判定示例

此脱敏合成 fixture 用于校准本 Skill 的分析，不是项目真实执行或业务验收记录；数值和协议仅适用于本示例。

## 输入

同日600000请求/86400秒；峰时含120000请求但未给持续时长。W-1 用日总量宣称峰值1000RPS。W-2 项目另给峰时600秒，求峰时平均RPS。W-3 稳态λ=50请求/秒，平均系统停留0.4秒，求在系统中的平均请求数。W-4 100会话，mix=60%浏览/40%结账，每会话各2/5请求，无重试，求总请求。判 UNSUPPORTED/CALCULABLE；输出W-2/W-3/W-4复算，不将平均叫瞬时峰值。

## 核对方法

1. 将每项输入写为数值、单位、时区/窗口、来源和覆盖：请求/交易/会话/用户不能互换；从交易mix及每交易请求数转换，注明重试与后台流量。
2. 日请求量只能复算全天平均；峰值需峰时流量比例与窗口宽度，缺窗口保持条件公式/区间，不自定峰时长度或峰倍数。
3. 明确开放到达率或封闭并发；Little's Law只在稳定窗口且单位一致时用L=λW，不能把在线用户或日活直接当并发。
4. 给候选曲线、会话长度/think time来源与校验计划；以实测到达/完成量和mix验证，未确认数值不能作为生产容量结论。
