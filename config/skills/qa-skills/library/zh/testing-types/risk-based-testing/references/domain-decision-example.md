# 领域判定示例

此脱敏合成 fixture 用于校准本 Skill 的分析，不是项目真实执行或业务验收记录；数值和协议仅适用于本示例。

## 输入

窗口30min；项目必须保护重复扣账，最小验证20min（同ID重试+账务一条+余额一致），另跨租户权限必须20min，文案检查5min。R1重复扣账已逃逸资损，R2跨租户权限无验证，R3文案轻微变化。用R1/R2 MUST_PROTECT、R3 DEFER、BUDGET ESCALATE，交付具体最低证据与不能在30min内全满足的事实，不自定降级授权。

## 逐项预期

| ID | DECISION |
| --- | --- |
| R1 | MUST_PROTECT |
| R2 | MUST_PROTECT |
| R3 | DEFER |
| BUDGET | ESCALATE |

## 核对方法

1. 按可观察影响、暴露/发生证据、可探测性与控制缺口建立定性锚点；缺项目数值模型不用自定分数乘积，未知概率保留不确定。
2. 每风险关联测试目标、层/平台、深度、数据、最低可观察证据、时长依据和剩余风险；高风险须有可证伪业务断言，而非仅更多用例。
3. 按约束分配窗口，关键最低保护与授权边界优先；时间不足明示延期项、替代验证、责任人和需Human接受的取舍，不自动免除门禁。
4. 保留正常/低风险对照与测试收益边界，输出选取理由和追加范围触发；计划优先级不构成实际执行或风险消除。
