# 领域判定示例

此脱敏合成 fixture 用于校准本 Skill 的分析，不是项目真实执行或业务验收记录；数值和协议仅适用于本示例。

## 输入

同月各20h。团队A 16h来自同selector重复实现、4h产品变化；B 16h来自runner宕机等待重试、4h产品变化；C 20h记录但无原因。M1建议A去重且保留业务断言；M2建议B优先稳定环境而不是重写所有测试；M3只因同20h给相同根因；M4评价C个人低效。用SUPPORTED/UNSUPPORTED/UNKNOWN判各建议并保持成本分组与来源，不能据总时长评绩效。 M5：C的具体成本成因无资料，判UNKNOWN。

## 核对方法

1. 固定测试资产/样本窗口/统计单位和工时来源，分产品变化、测试缺陷、基础设施、数据、重复实现及无法分类成本；同一工时不得重复计入多个原因。
2. 把触发事件、修改频率、工时范围、复核/返工与故障影响关联，区分一次建设和持续维护，不用单次样本推长期精确费用。
3. 对区间估计说明样本大小/代表性/异常点与公式；无货币费率只报工时，缺原因标UNKNOWN，不能评价个人效率。
4. 相同总时长但不同成因给不同可验证建议：变化解耦、修测试、环境稳定、数据隔离或去重；用同口径后续样本验证收益和质量保护。
