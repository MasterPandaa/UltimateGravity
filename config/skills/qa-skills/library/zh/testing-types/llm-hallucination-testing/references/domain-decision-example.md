# 领域判定示例

此脱敏合成 fixture 用于校准本 Skill 的分析，不是项目真实执行或业务验收记录；数值和协议仅适用于本示例。

## 输入

证据政策 D1-v2 第2条：自收货起14天内可退；第3条：运费不退。答案声明 H-1“14天内可退”，H-2“运费也退”，H-3“第9条规定终身保修”（提供文档只有1至3条，没有保修信息），H-4“今天新增海外条款”（当前政策页面无法访问）。给 SUPPORTED/CONTRADICTED/MISSING_SOURCE/UNASSESSABLE 的逐声明映射；不要因 H-1 正确整体通过，H-3 仅按提供证据判缺来源。

## 逐项预期

| ID | DECISION |
| --- | --- |
| H-1 | SUPPORTED |
| H-2 | CONTRADICTED |
| H-3 | MISSING_SOURCE |
| H-4 | UNASSESSABLE |

## 核对方法

1. 拆出独立可核对声明，包括数字/单位、实体、条件、时间和引用；为声明编号并保留答案原文、证据库版本和来源位置。
2. 标签定义：SUPPORTED 有相同范围的证据支持；CONTRADICTED 被证据明确反驳；MISSING_SOURCE 提供材料未支持且没有直接反证；UNASSESSABLE 因来源不可访问、范围/时效不明而不能比对。缺来源不等同已证明虚构。
3. 引用存在、能打开、相关及支持具体声明分别核对；来源真实却包含相反数字仍为矛盾，不能按整段一次定性。
4. 汇总保持逐声明分母、支持率与未知比例分开。无参考真值或取样覆盖不足时只给检验方案，不能证明事实准确。
