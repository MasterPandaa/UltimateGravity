# 领域判定示例

此脱敏合成 fixture 用于校准本 Skill 的分析，不是项目真实执行或业务验收记录；数值和协议仅适用于本示例。

## 输入

G1退款需求明确角色、金额、重复ID、失败处理及关闭条件=账务成功且余额一致；G2任务可暂停却没有终止/关闭条件；G3写“遵循附录B”但B未提供；G4同版本退款时限有7天/14天两值；G5项目仅网页，原生推送被范围文件排除。用COMPLETE/MISSING_RULE/MISSING_MATERIAL/CONFLICT/N/A逐项，给G2关闭缺口的影响和关闭证据，不误报G1。

## 逐项预期

| ID | DECISION |
| --- | --- |
| G1 | COMPLETE |
| G2 | MISSING_RULE |
| G3 | MISSING_MATERIAL |
| G4 | CONFLICT |
| G5 | N/A |

## 核对方法

1. 以范围/版本和适用角色、状态、规则、异常、关闭条件建立需求清单；每项注明来源与已提供材料覆盖，不把通常清单强套到不适用产品。
2. 分列MISSING_RULE（确认相关但规则未定义）、MISSING_MATERIAL（引用资料未提供）、CONFLICT（已提供规则冲突）、N/A（有范围理由不适用）与COMPLETE。
3. 缺口给原需求ID、缺失内容、影响场景、阻塞程度、责任人和最小澄清；空文档或未见字段不自动证明产品缺陷。
4. 关闭需权威补充规则/来源版本与可测试预期，并更新追踪；建议填法未经批准保持proposal，定义充分的正确对照不得报缺口。
