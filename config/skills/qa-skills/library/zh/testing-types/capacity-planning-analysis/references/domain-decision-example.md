# 领域判定示例

此脱敏合成 fixture 用于校准本 Skill 的分析，不是项目真实执行或业务验收记录；数值和协议仅适用于本示例。

## 输入

环境 E1 两实例、固定 mix；SLO p95<=200ms。测量100RPS:p95=150ms/CPU55%；150RPS:p95=260ms。K-1：建议由CPU55%宣称可支持300RPS。K-2：恒定到达130RPS，已验证服务100RPS，扩容等待60s，复算积压。K-3：失去一实例后没有测量。K-4：100RPS实测满足SLO。判定 UNSUPPORTED/CALCULABLE/UNKNOWN/SUPPORTED，保留条件和来源。

## 核对方法

1. 对每个观测点记录环境/配置/实例数、负载 mix、到达/完成吞吐、延迟分位数、错误率、CPU/内存/队列和时窗；把测量→SLO→容量候选的来源链列出。
2. 仅使用已测 SLO 可接受区间估计；CPU 百分比不能线性换算吞吐，未测点为候选，受下游、饱和与伸缩时延限制。
3. 按项目假设复算扩容等待期积压 = max(0,到达率−已验证服务率)×等待秒数；仅在速率恒定/队列模型适用时使用，并检查积压时延与恢复。
4. 故障余量用失去项目指定实例/依赖后的实际测量或明确条件模型；无故障数据不能宣布容量足够。安全余量、增长、成本及接受条件来自项目。
