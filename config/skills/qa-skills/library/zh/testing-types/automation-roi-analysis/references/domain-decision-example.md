# 领域判定示例

此脱敏合成 fixture 用于校准本 Skill 的分析，不是项目真实执行或业务验收记录；数值和协议仅适用于本示例。

## 输入

单位全部为人工小时，窗口每月：建设 12h，人工单次 1h，自动执行+复核单次 0.2h。R-1：每月20次，维护4h/月，分析3个月。R-2：每月5次，维护4h/月。R-3：每月20次，但变更使维护升到20h/月。R-4：缺执行频率。给每项 POSITIVE/NO_BREAK_EVEN/UNKNOWN，R-1 输出3个月净节省和整月回本点，勿换算成没有费率的钱。

## 逐项预期

## 核对方法

1. 固定候选、时间窗和单位；人工工时、自动执行占用、人工复核、维护工时与货币成本分开，换算必须有费率来源。
2. 以同一时间窗计算净节省 = 次数×(人工单次成本−自动单次成本)−维护成本−建设成本；ROI 的分子/分母须明示，未有货币换算只报工时。
3. 若每窗净运行节省 >0，break-even 窗口数 = 建设成本/每窗净运行节省；整数执行窗口向上取整。<=0 时在该假设下无回本点。
4. 对频率和变更引起的维护成本分别做项目给定的低/基准/高情景，记录来源及结论翻转点；缺数据输出公式/条件范围而非伪精确回报或自动采纳决定。
