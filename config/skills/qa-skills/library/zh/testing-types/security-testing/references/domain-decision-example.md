# 领域判定示例

此脱敏合成 fixture 用于校准本 Skill 的分析，不是项目真实执行或业务验收记录；数值和协议仅适用于本示例。

## 输入

授权仅隔离fixture租户A/B账号的只读权限核对。S1自动扫描零发现，业务权限未测试；S2 A读取自己的O1允许、无异常数据；S3 A读取B/O2收到200及B金额，日志和响应已提供；S4只有“验证删除权限”的计划，无执行也无删除授权。用S1 NOT_RUN（针对业务权限）、S2 CONTROL_PASS、S3 CONFIRMED、S4 DESIGNED，给威胁/控制/证据矩阵，不从S1外推安全。

## 逐项预期

| ID | DECISION |
| --- | --- |
| S1 | NOT_RUN |
| S2 | CONTROL_PASS |
| S3 | CONFIRMED |
| S4 | DESIGNED |

## 核对方法

1. 在已授权范围内建立资产/主体→威胁→控制→验证步骤→预期→证据/状态矩阵；记录环境、动作范围、停止条件与真实授权来源。
2. 正常授权访问与越权拒绝成对验证；拒绝路径要核对数据未泄露、工具/写入无副作用，不能只看错误响应或扫描结果。
3. 区分DESIGNED（未执行方案）、EXECUTED（有运行证据）、CONFIRMED（所给证据足以确认控制失效/漏洞）；未测业务授权保持NOT_RUN/UNKNOWN，静态迹象是候选。
4. 扫描无发现仅限扫描范围，不能外推系统安全；缺授权只给设计/静态分析，真实利用或生产动作须有明确允许范围，不生成危险内容或擅自扩测。
