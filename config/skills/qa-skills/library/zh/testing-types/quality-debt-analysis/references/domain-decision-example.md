# 领域判定示例

此脱敏合成 fixture 用于校准本 Skill 的分析，不是项目真实执行或业务验收记录；数值和协议仅适用于本示例。

## 输入

Q-1 180天旧的重复测试helper，每月维护1h，无高风险保护缺口。Q-2 新1天的退款测试完全mock被测对象，昨日漏检重复扣账，资损仍暴露。Q-3 已确认生产重复扣账Bug尚未修复。Q-4 helper重构ticket已关闭，但无行为回归或维护影响证据。Q-5 重构代码/独立回归/维护样本与负责人验收均有记录。用LOWER_PRIORITY/HIGHER_PRIORITY/PRODUCT_DEFECT/NOT_CLOSED/CLOSED分项判定，不单按年龄排序。

## 核对方法

1. 将已存在产品缺陷、测试/架构债务、暂时例外与数据缺口分列；每条记录来源、当前影响、形成原因、年龄和已有控制，不把所有未完成项叫债务。
2. 估计风险利息时说明变化路径：后续修改成本、故障暴露、检测延迟等可观察证据；没有费率/频率只给定性或条件范围，不自造金额。
3. 排序按业务影响、暴露、探测性、依赖和偿还成本/收益，年龄仅为一个信号；新生重大风险可优先于高龄轻微项。
4. 偿还完成需修复资产、独立行为检查、旧债务效果消失及责任人验收证据；完成ticket或文档不能单独关闭债务，风险接受有期限/授权。
