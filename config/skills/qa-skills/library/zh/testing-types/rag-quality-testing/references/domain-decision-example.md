# 领域判定示例

此脱敏合成 fixture 用于校准本 Skill 的分析，不是项目真实执行或业务验收记录；数值和协议仅适用于本示例。

## 输入

query问退款，检索C1-v2：“14天内且商品未使用可退；运费不退”；rubric要求含时间和未使用条件。A-1答“14天内可退运费”引用C1。A-2答“14天内且未使用可退，运费不退”引用C1。A-3答“14天内可退”引用C1，遗漏未使用。A-4问知识库未含的保修期限，正确说明缺依据并请求政策。用CONTRADICTED/PASS/INCOMPLETE/APPROPRIATE_REFUSAL，给声明-引用映射，不能以引用存在通过。

## 逐项预期

| ID | DECISION |
| --- | --- |
| A-1 | CONTRADICTED |
| A-2 | PASS |
| A-3 | INCOMPLETE |
| A-4 | APPROPRIATE_REFUSAL |

## 核对方法

1. 固定query/sample ID、知识库/索引/检索/模型/Prompt版本；建立query→检索chunk ID/版本→原子声明→引用位置→支持/矛盾/缺失映射，不以有引用判断grounding。
2. 引用准确性、声明支持与答案完整性分别评：遗漏必需条件即使已有声明全支持也可能不完整；按用户任务和项目rubric判。
3. 用知识覆盖内可回答与覆盖外应拒答对照，分别判正常任务正确性、错误拒答和应拒答幻觉；拒答率不能代替质量。
4. 缺chunk、真值、访问权限或门槛保持UNKNOWN/NOT_RUN；区分检索缺陷与生成曲解，报告证据范围和责任环节。
