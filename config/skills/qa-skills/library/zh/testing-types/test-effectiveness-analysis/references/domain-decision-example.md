# 领域判定示例

此脱敏合成 fixture 用于校准本 Skill 的分析，不是项目真实执行或业务验收记录；数值和协议仅适用于本示例。

## 输入

基线99/100通过。故障注入F1=重复扣账，T1仅断言标题而绿灯；F2=金额错误，T2账务断言失败；F3=环境断网，T3启动错误未进入业务断言；F4尚未注入。历史窗口一周另有重复扣账逃逸1个。用F1 MISSED/F2 DETECTED/F3 INCONCLUSIVE/F4 NOT_RUN，独立报告注入分母及历史逃逸，不能说99%通过率证明有效。

## 逐项预期

| ID | DECISION |
| --- | --- |
| F1 | MISSED |
| F2 | DETECTED |
| F3 | INCONCLUSIVE |
| F4 | NOT_RUN |

## 核对方法

1. 固定义务/故障类别、测试ID、实际生产逻辑、有效断言与可逃逸缺陷的映射；通过率/覆盖率只是信号，不能替代故障检出证据。
2. 历史逃逸记录观察窗口、暴露量、检出/漏检与关联来源；可控故障注入另列独立分母、控制组、环境和变异身份，不能混为生产缺陷率。
3. 检查失败是否来自目标业务断言，环境错误/超时不自动算有效检出；提供未检出原因候选和最小独立验证，不由相关性宣布因果。
4. 汇总每类故障的检出/漏检/未执行及剩余未知，建议优先补关键oracle；无故障或逃逸资料只交付评估设计，不宣布测试有效。
