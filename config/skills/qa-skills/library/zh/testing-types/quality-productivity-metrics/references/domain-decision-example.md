# 领域判定示例

此脱敏合成 fixture 用于校准本 Skill 的分析，不是项目真实执行或业务验收记录；数值和协议仅适用于本示例。

## 输入

同团队同窗口同复杂度：基线100个验收任务/100h，逃逸1；候选把用例拆成200条但仍100任务/100h，逃逸增至5。P-1有人称产能翻倍且质量改善。P-2候选另有相同任务100个/80h、逃逸1、返工工时可比且验收证据齐，允许说观察到工时效率改善。P-3团队A做支付、B做文案，只按用例数排名。用UNSUPPORTED/SUPPORTED/NOT_COMPARABLE，并报告投入/产出/质量/流程的平衡结论。

## 核对方法

1. 将投入工时/成本、可验收产出、质量缺陷/逃逸、流程等待/返工放在平衡视图，明确窗口、团队/任务统计单位、复杂度与产品风险。
2. 去重拆分/合并用例并核对验收，不以用例/commit数量代替价值；质量和返工下降证据缺失时不宣称生产率改善。
3. 同任务/复杂度/工具/窗口才能比较趋势；跨团队工作结构不同不能直接排名或用于个人绩效，暴露背景差异和不确定性。
4. 反操纵检查删难用例、漏报缺陷、延后记时及重跑计数；指标触发调查/改进实验而非自动因果结论或奖惩。
