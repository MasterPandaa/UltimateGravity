# 领域判定示例

此脱敏合成 fixture 用于校准本 Skill 的分析，不是项目真实执行或业务验收记录；数值和协议仅适用于本示例。

## 输入

项目按影响优先：资损可达100万元且无法自动追回为重大，即使低频也优先验证。R-1退款重复扣账仅出现1次、无幂等控制证据。R-2按钮颜色每天10次轻微偏差、任务仍完成。R-3新外部依赖没有故障或控制资料。R-4已测幂等防重且观测窗口无逃逸，但仍需说明剩余风险。判HIGHER_PRIORITY/LOWER_PRIORITY/UNKNOWN/CONTROL_EVIDENCED；不得自造乘积总分或宣布风险为零。

## 逐项预期

| ID | DECISION |
| --- | --- |
| R-1 | HIGHER_PRIORITY |
| R-2 | LOWER_PRIORITY |
| R-3 | UNKNOWN |
| R-4 | CONTROL_EVIDENCED |

## 核对方法

1. 从风险事件、受影响资产/人群、触发和当前控制建立登记表；影响、可能性、可探测性各给可观察证据锚点与来源，不凭印象填分。
2. 项目未指定量化规则时用有理由的定性排序；重大不可逆影响、授权边界与已知控制缺口单列，低频不自动降为低风险。
3. 证据不确定分别传播到概率/影响/控制置信度，给条件结论和最小判别验证，不把UNKNOWN乘成0或精确风险分。
4. 每项关联控制/测试、剩余风险、责任人与接受授权；风险排序是决策辅助，不代表漏洞、故障根因或实际验收。
