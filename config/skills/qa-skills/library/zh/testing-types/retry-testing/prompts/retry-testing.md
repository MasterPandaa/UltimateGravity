# 重试测试 Prompt

## 输入

先做输入审计，逐项记录 known、missing、conflicting、stale、out_of_scope、assumptions：

- known：已由来源直接支持的范围、重试策略或约束。
- missing：影响重试触发、退避、幂等、最大次数和重复副作用判断但尚未提供的材料。
- conflicting：不同来源之间不一致的目标、条件或行为。
- stale：可能过期的架构、版本、指标或运行记录。
- out_of_scope：不属于本 Skill、未授权或需要真实环境的动作。
- assumptions：为了形成受限初版而暂时采用的假设，必须标注验证方法。

## 你要做的事

1. 用一句话复述目标、对象、范围和成功标准。
2. 围绕重试触发、退避、幂等、最大次数和重复副作用建立失败场景、触发条件、预期关注点和证据需求。
3. 对每个场景标出优先级、责任角色、关闭条件和最小验证方法。
4. 把已确认事实、证据支持的推断、候选建议和 Human 决策分开。
5. 明确哪些内容只是设计准备，哪些内容需要后续隔离验证；不要宣称测试已经执行。

## 执行规则

- 先审计 known、missing、conflicting、stale、out_of_scope、assumptions，再分析。
- 每条结论必须能回溯到来源；没有来源时写待确认或验证建议。
- 使用重试策略作为领域锚点，使用 RTY-## 作为发现编号。
- 场景至少包含前置条件、刺激或动作、预期结果、证据和停止条件。
- 不注入故障、不访问真实依赖、不读取凭据、不调用生产系统。
- 不把文件存在、名称、模板或 dry-run 升级为执行、通过、覆盖率或发布证据。

## 领域操作与判定

以下步骤只对已提供材料做设计或静态比对；模型推导、候选集和 fixture 结论不构成真实执行证据。

1. 按错误合同分类可重试、永久拒绝和结果未知，明确“次数”是总尝试还是追加重试及每层调用关系。
2. 列端到端 deadline、每次超时、退避/抖动、HTTP Retry-After（延迟秒数或 HTTP-date） 与取消规则，按时间线计算尝试与等待的总预算，不自设退避数值。
3. 构造超时但已提交、重复消息和多层重试情景，按幂等键/业务 ID 查账本；可重试不等于可无条件重复副作用。
4. 检查永久错误停止、提示约束、取消后迟到结果与预算耗尽后的状态/对账，缺策略或未知提交时保留待确认。

**判定与交付：** 交付错误×尝试/时间预算×副作用表，明确嵌套实际调用数和超时提交不确定性。

HTTP Retry-After 单位与语法见 [RFC 9110 §10.2.3](https://www.rfc-editor.org/rfc/rfc9110.html#section-10.2.3)；该协议语法不替项目决定是否重试。

## 最低覆盖清单

- 重试策略和适用范围
- 主要失败模式与触发条件
- 暴露窗口、影响和优先级
- 现有控制、依赖和隔离边界
- 预期结果、证据状态和验证方法
- 关闭条件、剩余风险和 Human 决策
- facts、evidence-backed inferences、candidate recommendations、Human decisions

## 输出

### 1. 任务理解与范围

写明目标、对象、纳入项、排除项、成功标准和未授权动作。

### 2. 输入审计

分别列出 known、missing、conflicting、stale、out_of_scope、assumptions，并标明来源和时效性。

### 3. 重试策略与失败模型

说明重试触发、退避、幂等、最大次数和重复副作用的场景、触发条件、预期行为、影响、优先级和证据缺口。

### RTY-## 发现合同

每条发现必须包含：

- 对象/规则
- 来源
- 触发条件或适用范围
- 预期关注点/理由
- 证据状态
- 影响/优先级
- 责任角色
- 关闭条件
- 验证方法

### 4. 候选验证与剩余风险

把候选建议和实际执行分开，写出最小验证动作、停止/升级条件、剩余风险和待确认问题。

### 5. Human 决策

只列需要 Human 确认、风险接受、授权或发布判断的事项。

输出必须同时保留以下分区：事实、证据支持的推断、候选建议、Human 决策。

## 质量要求

- 领域内容必须针对重试触发、退避、幂等、最大次数和重复副作用，不能只是替换标题的通用模板。
- 不得把静态文案、计划或 dry-run 写成“测试已执行”“全部测试通过”或“发布已批准”。
- 数字、阈值、根因、恢复能力和安全结论都必须有来源。
- 让执行者知道下一步，让评审者能复核事实、推断、建议和 Human 决策的边界。
