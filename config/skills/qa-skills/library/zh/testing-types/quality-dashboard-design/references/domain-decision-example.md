# 领域判定示例

此脱敏合成 fixture 用于校准本 Skill 的分析，不是项目真实执行或业务验收记录；数值和协议仅适用于本示例。

## 输入

项目门禁：未关闭P0阻断，数据超过24h标STALE，未运行标NOT_RUN。D-1 面板99/100通过但剩余1项P0未关闭。D-2 上次绿灯数据48h前。D-3 测试无运行记录，却显示失败0并绿灯。D-4 当前100/100且无P0、来源run17可钻取、时窗与口径完整。给BLOCKED/STALE/NOT_RUN/PASS逐项决策，并映射发布决策/数据/行动，不把缺数据当零。

## 逐项预期

| ID | DECISION |
| --- | --- |
| D-1 | BLOCKED |
| D-2 | STALE |
| D-3 | NOT_RUN |
| D-4 | PASS |

## 核对方法

1. 按受众决策建立 问题→指标→口径/时窗→数据来源/版本→可采取行动→责任人 面板映射，不从易取数据倒推决策。
2. 展示值的分子分母、最后刷新时间与来源状态；0、null、NOT_RUN、BLOCKED、过期值分别呈现，禁止缺值补0或沿用过期绿灯。
3. 汇总必须保留P0/阻塞项、少数高风险群体和未知证据；总体通过率不能覆盖单项发布阻断，状态聚合来自项目规则。
4. 为每面板提供钻取到run/obligation/缺陷证据的路径、刷新契约与行动触发；没有数据或门槛时交付设计和缺口，不宣布当前质量通过。
