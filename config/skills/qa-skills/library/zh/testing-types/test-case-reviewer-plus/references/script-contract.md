# 输入准备脚本契约

可选 `scripts/run_*.py` 只准备解析后的输入材料或来源候选，输出 `NOT_ASSESSED`，不调用模型、不执行主 Prompt，不生成语义结论、风险优先级、完整用例或批准。正式分析由 Agent 按主 Prompt 执行；需要运行脚本时先读 `references/script-contract.md`。

输入必须非空；原文、行号、SHA-256 和来源标签均保留。Hash 标识解析后的材料，不证明源文件权威性；版本缺失保留 `UNKNOWN`。关键词不等于需求规则，候选不等于测试用例，无候选结论不等于零缺陷。

用密码长度 12–64、计算器和文本编辑器材料验证，不应出现材料外的促销、库存、支付结论。Markdown 的下划线、负号和比较符不做清洗。输出格式只改变展示，不提升证据等级；Word/TSV 仍须保留 `NOT_ASSESSED` 与来源。

准备完成后，将材料交给当前 Agent 按 `prompts/` 主 Prompt 推导可观察业务预期、风险与待人工决策。
