# 领域判定示例

此脱敏合成 fixture 用于校准本 Skill 的分析，不是项目真实执行或业务验收记录；数值和协议仅适用于本示例。

## 输入

字典v1：本月新缺陷按distinct defect_id；首次通过率按distinct test_id首次尝试。事件D1创建/关闭/重开，D2创建，D1重复导入；测试T1首FAIL后重跑PASS，T2首PASS，T3计划但无执行。K-1有人说新缺陷4个。K-2首通过率用重跑替代失败而说100%。K-3按定义计算新缺陷与首次执行通过率。K-4声称T3通过。给WRONG/CALCULABLE/UNKNOWN，保留缺陷实体、首次分母和未执行状态。

## 核对方法

1. 建立指标字典：决策目的、统计单位、分子/分母、时窗/时区、筛选/去重、缺失处理、版本、来源与lineage；率的分母不能隐式变化。
2. 区分缺陷实体与状态事件、首次执行与重跑、关闭与重开；按项目唯一键和事件时间聚合，避免把重复ID/重开计成新缺陷或重试冲高通过率。
3. 复算样本并核对分母覆盖、延迟与排除理由；缺记录保持未知，不能补0。数据异常先标测量问题，未有证据不归因产品质量。
4. 输出计算例、解释限制、监控阈值来源与行动；跨项目比较要对齐定义与窗口，不把指标相关性写成因果。
